# COVID-19 Data Analysis & Power BI Dashboard

## 📊 Project Overview

This project focuses on analyzing COVID-19 data and building an interactive Power BI dashboard to explore the global spread of the pandemic and country-level trends.

The dashboard provides insights into confirmed cases, active cases, recoveries, deaths, and different COVID-19 rates across countries and WHO regions.

---

## 🎯 Project Objectives

- Analyze the global impact of COVID-19.
- Track new confirmed cases, recoveries, and deaths over time.
- Compare COVID-19 cases across WHO regions.
- Analyze country-level COVID-19 trends.
- Calculate active, recovery, and death rates.
- Create an interactive and user-friendly dashboard.

## 📈 Dashboard Features

### 🌍 Global Overview

The global dashboard includes:

- Total Confirmed Cases
- Total Active Cases
- Total Recovered Cases
- Total Deaths
- Active Rate
- Recovery Rate
- Death Rate
- New Cases Over Time
- New Recoveries Over Time
- New Deaths Over Time
- Top 5 WHO Regions by Confirmed Cases
- Top WHO Regions by Death Rate
- Active & New Cases by WHO Region

### 🌎 Country Analysis

The country-level dashboard allows users to select a country and analyze:

- Total Confirmed Cases
- Total Active Cases
- Total Recoveries
- Total Deaths
- Recovery Rate
- Death Rate
- Confirmed Cases Trend
- Recovered Cases Trend
- Deaths Trend
- Top 10 Countries by Confirmed Cases
